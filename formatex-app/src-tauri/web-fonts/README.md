# HTML serif outlines

Generated from Typst assets 0.15.1 NewCM10 Regular/Bold/Italic/BoldItalic using `scripts/prepare-html-serif.py`. Cubic outlines are converted to quadratic outlines with at most one font-unit error (1/1000 em), preserving shaping tables and metrics. The internal family is renamed Formatex NewCM Web; HTML uses the requested CSS family name. These assets do not participate in PDF font selection.
